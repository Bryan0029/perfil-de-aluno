# Perfil de Aluno

Projeto acadêmico desenvolvido em **Kotlin** com o objetivo de praticar e consolidar conceitos da linguagem aprendidos em sala de aula durante a formação técnica em Informática.

## Objetivo

Explorar funcionalidades e estruturas fundamentais do Kotlin por meio de exercícios e pequenas implementações práticas, reforçando o aprendizado da linguagem e a lógica de programação.

## Tecnologias utilizadas

- Kotlin
- IntelliJ IDEA (se foi a IDE utilizada)

## Conteúdos praticados

- Estruturas condicionais
- Operadores aritméticos e relacionais
- Entrada e saída de dados
- Lógica de programação
- [Outros conteúdos efetivamente trabalhados]

## Contexto acadêmico

Este repositório faz parte da minha trajetória de aprendizado em programação, reunindo práticas desenvolvidas durante as aulas.
